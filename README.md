# Image Finder

Image search application with a Node.js/Express backend proxy, so the Unsplash API key never reaches the browser. Paginated results and a responsive image gallery.

**Live demo:** https://imagefinder2025.netlify.app/ · **Portfolio:** https://portfoliobob.netlify.app/#projects

## Features

- Node.js/Express backend proxy
- Secure API integration (key stays on the server)
- Result pagination (“Show more”)
- Responsive image gallery

**Stack:** JavaScript · Node.js · Express · Unsplash API
